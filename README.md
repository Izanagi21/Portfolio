# Jaymark Talento Portfolio

Static portfolio landing page configured for Vercel.

## Deploy to Vercel

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. In Vercel, select **Add New → Project** and import the repository.
3. Leave the project root as the repository root. The included `vercel.json`
   builds the static site into the `portfolio-website/public` output folder.
4. Select **Deploy**.

Vercel will redeploy the site automatically after each push to the production
branch.
